# Exam Rank 06 - 42 School

Welcome to the **Exam Rank 06** repository. This repository contains solutions, tests, study guides, and resources for the final exam of the 42 School Common Core.

## Directory Structure

*   **`Training/`**: Contains the main study guides (in English and Portuguese) and the heavily commented source code solutions (Array and Struct based) for `mini_serv`.
*   **`Tests/`**: Contains a custom tester I developed for this exam (`42-mini_serv-tester`).
*   **`Passed/`**: Contains the raw, successful attempt that passed the exam.
*   **`Repositories/`**: A curated collection of submodules pointing to other students' repositories for reference and alternative solutions.

## Disclaimer

The solutions in `Repositories/` belong to their respective authors and were not tested by me. Use them at your own risk. The solutions provided in `Training/` have been validated and tested.

Good luck with your exam!
